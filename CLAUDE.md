# SQLBridge

Browser-only Oracle → PostgreSQL SQL converter. The site in `docs/` is published by GitHub Pages from `main`; `docs/converter.py` runs inside Pyodide in a Web Worker. Checks: `python3 test_converter.py`, `node --check docs/app.js docs/worker.js`.
